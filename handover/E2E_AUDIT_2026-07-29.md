## Persistence: Fakta yang Terverifikasi

1. Dengan backend mock sukses, empat module mengirim `saveParticipantProgress` dengan `module_id`, `chapter_id`, status, dan score yang benar. AI Modern gagal pada ketiga jalur yang sudah dikenal (#81–#82).
2. Dengan backend mock mengembalikan `{status: "error"}`, kuis Python tetap menulis `QuizDone=true`, menampilkan skor, dan mengunci tombol sebagai “Kuis Sudah Dikirim”. Respons backend tidak diperiksa (#85).
3. Dalam browser tanpa sesi, submit kuis juga terkunci lokal tanpa request `/__gas`. Ini membuktikan UI selesai tidak dapat dipakai sebagai bukti data sudah masuk backend.
4. Posting diskusi menyatakan “tersimpan di browser ini”, menulis localStorage, dan tidak mengirim persistence request ke backend (#91).
5. Read-back production belum dapat dibuktikan pada eksekusi ini karena sesi MCP kedaluwarsa dan `TEST_PARTICIPANT_NIK`/`TEST_PARTICIPANT_PASSWORD` tidak tersedia sebagai secret environment.
