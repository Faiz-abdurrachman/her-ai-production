HerAI Gallery Asset Pack
========================

wide_pastel_pink_scrapbook_style_ui_graphic_design.png

Total extracted items: 86

Folders
-------
cropped_png/
    Exact pixel crops from the generated asset sheet, grouped by category.
    These preserve the original quality and pink background from the flattened source.

transparent_decorations_approx/
    Approximate transparent versions for flowers and doodles.
    IMPORTANT: the original generated sheet is a single flattened PNG, not layered source artwork.
    Therefore true clean transparency cannot be recovered perfectly. Use these as optional convenience assets.

reference_cards/
    Convenience copies of the two main card designs:
    - submitted project card
    - reserved / empty project card

manifest.csv
    Asset names and crop coordinates.

contact_sheet.png
    Preview index of all extracted assets.

Notes
-----
- All UI/card crops are intentionally kept as exact source crops.
- The project/card assets can be given to an AI coding agent as visual references.
- For production implementation, recreating card shells in HTML/CSS is preferable to using card screenshots as UI.
- Flowers/doodles can be used as decorative raster assets; use the transparent approximation only when it looks clean enough.
