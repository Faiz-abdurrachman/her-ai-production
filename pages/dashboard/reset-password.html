Reset Password Peserta

Alat khusus superadmin untuk mereset password akun peserta

System Admin

Root Access

Area Kritis / Root Access

Tindakan reset password akan langsung berlaku dan tercatat di audit trail. Pastikan NIK peserta benar sebelum melanjutkan.

Reset Password Peserta

Masukkan NIK 16 digit peserta yang passwordnya ingin direset

Minimal 6 karakter, tidak boleh diawali "pw$1$"

Catatan Penting

Efek Langsung

Password baru langsung aktif. Password lama tidak berlaku lagi setelah reset.

Tercatat di Audit Trail

Setiap tindakan reset password dicatat otomatis di audit trail beserta identitas admin.

Informasikan Manual

Sistem tidak mengirim notifikasi otomatis. Sampaikan password baru ke peserta secara langsung.

Akses Terbatas

Hanya superadmin yang dapat mengakses fitur ini. Backend memvalidasi ulang hak akses.

Validasi Password: Min 6 karakter, maks 72 karakter, tidak boleh diawali pw$1$
